# Documentation

This folder is the source of truth for project documentation.

## Folders

- `architecture/` records system structure, boundaries, and technical design.
- `product/` records user roles, learning model, and product scope.
- `engineering/` records development standards once the stack is selected.
- `operations/` records release, support, and incident procedures.
- `security/` records security, privacy, and compliance expectations.
- `decisions/` stores architecture decision records.

Documentation should be updated before or alongside implementation work.
