# Learning Model

This document captures early product thinking for a Chinese learning platform.

## Core Learning Concepts

- Lessons: structured units of instruction.
- Hanzi: character learning, stroke awareness, radicals, and recognition.
- Vocabulary: words, meanings, usage examples, pronunciation, and review metadata.
- Grammar: patterns, explanations, examples, and exercises.
- Pronunciation: pinyin, tone marks, listening, and speaking practice.
- Assessment: quizzes, placement, review, and mastery checks.
- Progress: learner state across lessons, skills, and review history.

## Open Questions

- Which learner levels are supported first?
- Which standards should be mapped first, such as HSK or CEFR?
- Which languages are required for explanations and interface text?
- Will teachers author lessons directly in the platform or through an external workflow?
