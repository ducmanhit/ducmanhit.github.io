# Platform

This folder is the home for the future production Chinese Learning Platform.

It is intentionally empty of application features right now. The folders inside define ownership boundaries for future implementation.

## Folders

- `apps/` for deployable applications.
- `services/` for backend service boundaries.
- `packages/` for shared libraries.
- `content/` for learning content source material.
- `data/` for database, migration, seed, import, and fixture planning.
- `infrastructure/` for deployment and production environment planning.
- `scripts/` for project automation.
- `tests/` for cross-project test suites.
- `design/` for product design and research artifacts.
- `config/` for shared configuration templates.
- `tools/` for internal developer and content tools.
